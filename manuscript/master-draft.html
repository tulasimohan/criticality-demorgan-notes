1 1. Formal Foundations & Definitions

Following contents.tex (Section 2) and project_macros.tex:

Definition 1 (DeMorgan Formula & Size)

A DeMorgan formula \(F\) over variable index set \(X\) is a Boolean formula composed of \(\lor\) (OR), \(\land\) (AND) operations and literals \(\{x_i, \bar{x}_i\}_{i \in X}\). The size of \(F\), denoted \(L(F)\), is the total number of leaves (literal occurrences) in the formula tree. For a variable \(x\), \(L_F(x)\) denotes the number of leaves labeled with literal \(x\) or \(\bar{x}\).

Definition 2 (Random Restriction \(\mathcal{R}_p\))

A \(p\)-random restriction \(\rho \sim \mathcal{R}_p\) on variable set \(X\) is a distribution over \(\{0, 1, *\}^X\) such that independently for each \(x \in X\): \[\Pr[\rho(x) = *] = p, \quad \Pr[\rho(x) = 0] = \frac{1-p}{2}, \quad \Pr[\rho(x) = 1] = \frac{1-p}{2}.\] An ordered restriction is a sequence of pairs \(((x_1, a_1), \dots, (x_k, a_k))\) specifying an explicit variable evaluation order.

Definition 3 (Downward-Closed Set of Restrictions)

Let \(\Delta \subseteq \{0, 1, *\}^X\). \(\Delta\) is said to be downward-closed if for every \(\rho \in \Delta\), substituting any \(*\) with a constant \(c \in \{0, 1\}\) preserves membership: \[\rho \in \Delta \implies \rho \circ (x_i \gets c) \in \Delta \quad \forall x_i \text{ such that } \rho(x_i) = *.\]

2 2. Canonical Decision Trees with Simultaneous Balancing

In contents.tex (Sections 3 & 4), the Canonical Decision Tree \(\mathrm{CDT}(F, \rho)\) is defined constructively:

2.1 Base Cases

  1. Constant: If \(F|_\rho \equiv c \in \{0, 1\}\), \(\mathrm{CDT}(F, \rho)\) is a single leaf node labeled \(c\).
  2. Single Literal: If \(F = \ell\) and \(\rho(\mathrm{var}(\ell)) = *\), \(\mathrm{CDT}(F, \rho)\) is a single decision node querying \(\mathrm{var}(\ell)\) with child leaves labeled \(0\) and \(1\).

2.2 Recursive Construction for \(F = F_1 \lor F_2\)

Let \(\Gamma_1 = \mathrm{CDT}(F_1, \rho)\). - For each leaf \(u \in \Gamma_1\) labeled \(1\), \(u\) remains \(1\) (witnessing satisfaction of the OR gate). - For each leaf \(u \in \Gamma_1\) labeled \(0\) with root-to-leaf path assignment \(\pi_u\), attach \(\mathrm{CDT}(F_2, \rho \circ \pi_u)\). - Apply the simultaneous balancing operator \(\mathrm{Balance}(\Gamma)\) to guarantee path variable symmetry.

Claim (Source of a Cloned Path — contents.tex, Claim 3.1)

Let \(\Gamma'' = \mathrm{Balance}(\mathrm{CDT}(F, \rho))\) and let \(\alpha = (x_1 \gets a_1, \dots, x_t \gets a_t)\) be a path in \(\Gamma''\). Then either \(\alpha\) was an original path generated during tree exploration, or it was generated by the balancing operation to mirror an existing counter-path over the identical variable set.

3 3. The Banyan Trunk Decomposition Theorem

This theorem forms the core of the non-inductive proof technique in contents.tex (Lemma 4.3) and Criticality proof.md:

Definition 4 (Exploration Certificate)

Given a sequence of \(t\) variables \(\bar{x} = (x_1, \dots, x_t)\), a Trunk \(\mathcal{T}\), and bit-strings \(\mathbf{b}_T = \{b_v\}_{v \in \mathcal{T}}\), the Exploration Certificate \(\mathrm{EC}(\mathcal{T}, \mathbf{b}_T, \bar{x})\) is the tuple: \[\mathrm{EC}(\mathcal{T}, \mathbf{b}_T, \bar{x}) = (t_v, X_v, \eta_v, \alpha_v, \beta_v)_{v \in \mathcal{T}}\] where: 1. \(t_v(\mathcal{T})\) is the number of terminal nodes of \(\mathcal{T}\) under node \(v\). 2. \(X_v(\mathcal{T}, \bar{x})\) is the subsequence of variables from \(\bar{x}\) assigned to terminal nodes under \(v\) in in-order traversal. 3. Pre-restriction \(\eta_v\) is defined recursively: - \(\eta_{\mathrm{root}} = \langle \rangle\). - \(\eta_v = \eta_{\mathrm{parent}(v)} \circ \alpha_{\mathrm{lsibling}(v)}\) if \(v\) has a left sibling in \(\mathcal{T}\), else \(\eta_v = \eta_{\mathrm{parent}(v)}\). 4. Original path \(\beta_v = \langle X_v \gets b_v \rangle\). 5. Inherited path \(\alpha_v = \beta_{\mathrm{parent}(v)}[1, t(v)]\).

Theorem (Banyan Decomposition Lemma — contents.tex, Lemma 4.3)

Let \(F\) be a DeMorgan formula, \(\rho\) a restriction, and \(t \in \mathbb{N}\). If \(\mathrm{CDT}^{(a)}_z(F, \rho) = \langle x_1 \gets a_1, \dots, x_t \gets a_t \rangle\), then there exists a unique Trunk \(\mathcal{T}\) whose aerial roots \((v_1, \dots, v_t)\) correspond to variables \((x_1, \dots, x_t)\) and unique bit-strings \(\mathbf{b}_T = \{b_v\}_{v \in \mathcal{T}}\) satisfying:

  1. Routing Condition \(\mathcal{A}_F(\rho, \bar{x}, \mathcal{T}, \mathbf{b}_T)\): For each non-terminal node \(v \in \mathcal{T}\):
    • If \(F_v = F_{v_1} \lor F_{v_2}\), then for \(j \in \{1, 2\}\):
      • If \(F_{v_j}|_{\rho, \eta_{v_j}} \equiv 0\), then \(v_j \notin \mathcal{T}\).
      • If \(F_{v_j}|_{\rho, \eta_{v_j}} \not\equiv 0\), witnessed by \(F_{v_j}|_{\rho, \eta_{v_j}, \beta_{v_j}} \equiv 1\) and \(\mathrm{Assoc}_0(F_{v_j}|_{\eta_{v_j}}, \rho, \alpha_{v_j}) = \beta_{v_j}\).
    • Dual conditions hold for AND nodes \(F_{v_1} \land F_{v_2}\).
    • Crucially: For any fixed \((\bar{x}, \mathcal{T}, \mathbf{b}_T)\), the set \(\{\rho : \mathcal{A}_F(\rho, \bar{x}, \mathcal{T}, \mathbf{b}_T)\}\) is downward-closed.
  2. Aerial Roots Literal Condition \(\mathcal{B}_F(\rho, \bar{x}, \mathcal{T}, \mathbf{b}_T)\): For each aerial root \(v_i\) of \(\mathcal{T}\), the subformula simplifies to a literal in \(x_i\): \[F_{v_i}|_{\rho \circ \eta_{v_i}} \text{ is a literal in the single variable } x_i.\]

4 4. Probability Upper Bound & Convexity

Following Criticality proof.md and non-inductive proof.tex:

4.1 Step 1: Base Case Peeling on Aerial Roots

Since each \(F_{v_i}|_{\rho \circ \eta_{v_i}}\) reduces to a literal in \(x_i\), and \(\mathcal{A}\) is downward-closed: \[\sum_{x_i} \Pr[\mathcal{B}_i \mid \mathcal{B}_1, \dots, \mathcal{B}_{i-1}, \Delta] \le 2p \sqrt{L(T_i)}\] Peeling all \(t\) aerial roots yields: \[\sum_{\bar{x}} \Pr[\mathcal{B}(\bar{x}, \mathcal{T}, \mathbf{b}_T) \mid \mathcal{A}] \le (2p)^t \prod_{i=1}^t \sqrt{L(T_i)}\]

4.2 Step 2: Global Convexity Bound

Taking the maximizer \(\bar{v}^*_{T, b_T} = \arg\max_{\bar{v}} \Pr[\mathcal{A}(\bar{v}, T, b_T)]\) and defining \(\mu(T) = \sum_{b_T} \Pr[\mathcal{A}(\bar{v}^*, T, b_T)]\):

\[\begin{aligned} \Pr[\mathrm{CDT}_{\mathrm{depth}}(F|_\rho) \ge t] &\le (2p)^t \sum_T \mu(T) \prod_{i=1}^t \sqrt{L(T_i)} \\ &= (2p)^t \left(\sum_T \mu(T)\right) \cdot \mathbb{E}_{T \sim \mu}\left[\prod_{i=1}^t \sqrt{L(T_i)}\right] \\ &\le (2p)^t \sqrt{\sum_T \mu(T)} \sqrt{\mathbb{E}_{T \sim \mu}\left[\prod_{i=1}^t L(T_i)\right]} \quad (\text{by Jensen\'s Inequality}) \\ &\le (2p)^t \sqrt{\sum_T \prod_{i=1}^t L(T_i)} \le (2p\sqrt{L})^t. \end{aligned}\]
